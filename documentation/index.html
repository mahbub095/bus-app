SonyaBus — Bus Ticket Booking System

Full-stack booking platform · Laravel 12 backend · React 19 customer app · ZiniPay payments · SMS notifications

Introduction

SonyaBus is a complete bus ticket booking system with two separate surfaces:

  • Customer React app — search schedules, choose seats on an interactive seat map, pay online, manage tickets, apply promo codes.
  • Laravel Admin dashboard — manage coaches, routes, schedules, bookings, cancel requests, promotions, users & roles, reports (PDF & Excel), and all gateway settings.
ItemDetail
BackendLaravel 12, PHP 8.2+, MySQL / SQLite
FrontendReact 19, Vite 8
PaymentZiniPay
SMSSMS.NET.BD, BulkSmsBD, or custom GET/POST gateway
AuthLaravel Sanctum (customer API) + session (admin)
Reports11 report types — PDF (DomPDF) & Excel export

License Activation

SonyaBus requires a valid CodeCanyon purchase code to operate. Activation happens through the built-in installation wizard the first time you open the app. The application will automatically redirect every request to /install until a license is verified.

What you need

ItemWhere to find it
Purchase Code Envato Market → Your Account → Downloads → click Licenses & Purchase Codes next to SonyaBus
Personal Token Generate at build.envato.com/create-token. Enable the Verify Purchases permission. The token is used once during verification and is never stored.

Activation wizard — steps

  1. License — Enter your purchase code and Envato personal token. The system calls the Envato Market API to confirm the code belongs to this product.
  2. Database — Enter your MySQL host, port, database name and credentials. A live connection test is performed before saving.
  3. Admin Account — Create the initial super-admin login (name, email, password).
  4. Finalize — Runs php artisan migrate, creates the admin account, and clears all caches. You are redirected to the admin dashboard.
✅ After activation the wizard is no longer accessible to unauthenticated visitors. Your .env file is updated with APP_LICENSED=true automatically.

Re-verifying after a domain change

If you migrate to a new domain, go to Admin → License (super admin only) and enter your purchase code and a new Envato personal token. The license record will be updated with the new domain.

⚠ One purchase = one live installation. A Regular License covers a single end product for a single client. Purchase an Extended License or additional Regular Licenses for multiple deployments. See the Envato license terms for details.

Installation

Step 1 — Upload & extract

Upload the package ZIP to your server and extract it. You should have a backend/ and a frontend/ directory.

Step 2 — Install backend dependencies

cd backend
composer install --no-dev --optimize-autoloader

Step 3 — Configure backend environment

cp .env.example .env
php artisan key:generate

Edit backend/.env and set at minimum: APP_URL, APP_FRONTEND_URL, DB_* credentials, and ENVATO_ITEM_ID (your CodeCanyon item ID). See the Backend .env section for all values.

ℹ ENVATO_ITEM_ID is the numeric ID in your CodeCanyon item URL:
https://codecanyon.net/item/sonyabus/12345678 → set ENVATO_ITEM_ID=12345678

Step 4 — Set storage permissions

chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache

Step 5 — Configure your web server

Point your web server to backend/public/. See the Web Server section for Nginx and Apache examples.

Step 6 — Run the Installation Wizard

Open your backend URL in a browser. You will be automatically redirected to the installation wizard at https://your-backend-domain.com/install. Complete all 4 steps: License → Database → Admin Account → Finalize.

The wizard will run database migrations and create your super-admin account.

⚠ After installation, the wizard creates demo data only if you ran php artisan db:seed manually. The wizard itself does not seed demo data — your database starts clean.

Step 7 — Install & build the frontend

cd ../frontend
cp .env.example .env
# Edit frontend/.env — set VITE_API_BASE_URL and VITE_ZINIPAY_API_KEY
npm install
npm run build

The compiled app will be in frontend/dist/. Point your web server document root here for the customer-facing site.

(Optional) Seed demo data

To populate the system with sample stations, routes, schedules, and user accounts for testing:

php artisan db:seed
🔴 Never seed on a live production database. The seeder creates demo accounts with password password123.

cPanel-এ Install করার পদ্ধতি

Shared hosting (Hostinger, Namecheap, Bluehost ইত্যাদি) যেখানে cPanel আছে সেখানে SonyaBus install করতে নিচের steps অনুসরণ করুন।

⚠ শর্ত: cPanel-এ PHP 8.2+ এবং SSH / Terminal অথবা Composer Manager plugin থাকতে হবে। বেশিরভাগ modern shared hosting-এ cPanel Terminal পাওয়া যায়।

পদক্ষেপ ১ — দুটো Subdomain তৈরি করুন

SonyaBus-এর backend এবং frontend আলাদা domain/subdomain-এ থাকে। cPanel → Domains / Subdomains থেকে তৈরি করুন:

উদ্দেশ্যSubdomain উদাহরণDocument Root
Backend (Laravel API + Admin) api.yourdomain.com public_html/api/public
Frontend (React App) app.yourdomain.com public_html/app
ℹ বিকল্প: আলাদা subdomain না করে main domain-এও রাখা যায়। সেক্ষেত্রে yourdomain.com → frontend, yourdomain.com/api নয় বরং api.yourdomain.com → backend রাখাই ভালো।

পদক্ষেপ ২ — ফাইল আপলোড করুন

  1. ZIP প্রস্তুত করুন: আপনার কম্পিউটারে project-এর দুটো folder আলাদা করুন — backend.zip এবং frontend.zip।
  2. cPanel → File Manager খুলুন। public_html/ ফোল্ডারে যান।
  3. backend.zip আপলোড করুন এবং public_html/api/ ফোল্ডারে extract করুন।
    ফলে তৈরি হবে: public_html/api/app/, public_html/api/public/ ইত্যাদি।
  4. frontend/dist/ এর সব contents আপলোড করুন public_html/app/ ফোল্ডারে।
    (dist folder-এর ভেতরের files, folder নিজে নয়)
ℹ dist folder তৈরি: Frontend build করতে আপনার local machine-এ: 
cd frontend
npm install
npm run build
তৈরি হওয়া frontend/dist/ ফোল্ডারের সব files cPanel-এ আপলোড করুন।

পদক্ষেপ ৩ — Subdomain Document Root ঠিক করুন

cPanel → Domains → api.yourdomain.com এর Document Root অবশ্যই public_html/api/public হতে হবে — public_html/api নয়। এটা না হলে Laravel 500 error দেবে।

পদক্ষেপ ৪ — .env ফাইল তৈরি করুন

cPanel File Manager → public_html/api/ ফোল্ডারে যান। .env.example ফাইলটি copy করে নাম দিন .env। তারপর Edit করুন:

APP_DEBUG=false
APP_URL=https://api.yourdomain.com

ENVATO_ITEM_ID=12345678   <-- আপনার CodeCanyon item ID

DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=yourusername_sonyabus   <-- cPanel database নাম
DB_USERNAME=yourusername_dbuser     <-- cPanel database user
DB_PASSWORD=your_db_password

পদক্ষেপ ৫ — MySQL Database তৈরি করুন

cPanel → MySQL Databases:

  1. নতুন database তৈরি করুন: যেমন yourusername_sonyabus
  2. নতুন user তৈরি করুন: যেমন yourusername_dbuser — শক্তিশালী password দিন
  3. User-কে database-এ ALL PRIVILEGES দিন

পদক্ষেপ ৬ — Terminal থেকে Composer চালান

cPanel → Terminal (অথবা SSH client যেমন PuTTY):

# backend folder-এ যান
cd public_html/api

# APP_KEY generate করুন
php artisan key:generate

# Dependencies install করুন

⚠ Composer না থাকলে: cPanel-এ Softaculous বা hosting provider-এর "Composer Manager" ব্যবহার করুন। অথবা local machine-এ composer install --no-dev চালিয়ে vendor/ folder-সহ আপলোড করুন।

পদক্ষেপ ৭ — .htaccess চেক করুন

public_html/api/public/.htaccess ফাইলটি আছে কিনা দেখুন। না থাকলে নিচেরটা তৈরি করুন: 

<IfModule mod_rewrite.c>
    <IfModule mod_negotiation.c>
        Options -MultiViews -Indexes
    </IfModule>

    RewriteEngine On

    # Handle Authorization Header
    RewriteCond %{HTTP:Authorization} .
    RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}]

    # Redirect Trailing Slashes If Not A Folder...
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_URI} (.+)/$
    RewriteRule ^ %1 [L,R=301]

    # Send Requests To Front Controller...
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteRule ^ index.php [L]
</IfModule>

পদক্ষেপ ৮ — Frontend-এর .htaccess তৈরি করুন

React app-এর জন্য public_html/app/.htaccess তৈরি করুন (React Router-এর জন্য সব request index.html-এ redirect করতে হবে): 

<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteBase /

    # Don't rewrite files or directories
    RewriteCond %{REQUEST_FILENAME} -f [OR]
    RewriteCond %{REQUEST_FILENAME} -d
    RewriteRule ^ - [L]

    # Rewrite everything else to index.html
    RewriteRule ^ index.html [L]
</IfModule>

পদক্ষেপ ৯ — Installation Wizard চালান

Browser-এ https://api.yourdomain.com খুলুন। Automatically /install এ redirect হবে। 4টি step সম্পন্ন করুন: License → Database → Admin → Finalize.

পদক্ষেপ ১০ — Cron Job সেটআপ করুন

cPanel → Cron Jobs → "Add New Cron Job":

* * * * * /usr/bin/php /home/yourusername/public_html/api/artisan schedule:run >> /dev/null 2>&1
ℹ php path: আপনার hosting-এ php binary path আলাদা হতে পারে। Terminal-এ which php চালিয়ে দেখুন।

পদক্ষেপ ১১ — Queue Worker সেটআপ করুন

SMS notification queue-এর জন্য। cPanel → Cron Jobs:

* * * * * /usr/bin/php /home/yourusername/public_html/api/artisan queue:work --stop-when-empty >> /dev/null 2>&1
⚠ Shared hosting limitation: বেশিরভাগ shared hosting-এ persistent background process চালানো যায় না। তাই queue:work এর বদলে queue:work --stop-when-empty ব্যবহার করুন এবং cron দিয়ে প্রতি মিনিটে চালান।
✅ সব শেষ! এখন https://api.yourdomain.com/admin → admin dashboard, https://app.yourdomain.com → customer app।

Web Server Configuration

Nginx — recommended setup

Serve the React customer app on the main domain and the Laravel API/admin on a subdomain (or same domain with path-based proxy).

# Customer React app — serves frontend/dist/
server {
    listen 80;
    server_name yourdomain.com;
    root /var/www/sonyabus/frontend/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}

# Laravel backend — serves backend/public/
server {
    listen 80;
    server_name api.yourdomain.com;
    root /var/www/sonyabus/backend/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* { deny all; }
}

Apache — .htaccess (included in backend/public/)

Laravel ships with a public/.htaccess file. Ensure mod_rewrite is enabled and AllowOverride All is set for the document root.

DocumentRoot /var/www/sonyabus/backend/public
<Directory /var/www/sonyabus/backend/public>
    Options -Indexes +FollowSymLinks
    AllowOverride All
    Require all granted
</Directory>

Same-domain deployment (API under /api path)

If you want both on one domain (e.g. yourdomain.com → React, yourdomain.com/api → Laravel), add a proxy location to your Nginx config and set VITE_API_BASE_URL=/api.

location /api/ {
    proxy_pass http://127.0.0.1:8000/api/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

Customer App Overview

The React app is served from frontend/dist/ after building.

  • Search — select origin, destination, date, and optionally coach type (AC / Non-AC).
  • Seat map — interactive seat picker showing available, booked (M/F), and blocked seats. Seats are temporarily held for 2 minutes while the customer completes checkout.
  • Checkout — enter passenger details, apply a promo code, choose payment method, and confirm.
  • Payment — redirects to ZiniPay; on success the booking status is updated to SOLD and an SMS confirmation is sent.
  • My Tickets — authenticated customers can view all their bookings and request cancellations.
  • Offers — displays active promo codes from the admin panel.
  • Maintenance mode — if enabled in Admin → Site Settings, the app shows a maintenance page (site-settings endpoint remains accessible).

ZiniPay Payment Setup

  1. Create a merchant account at zinipay.com and obtain your API key.
  2. Set in backend/.env: 
    ZINIPAY_API_KEY=your_api_key_here
ZINIPAY_BASE_URL=https://api.zinipay.com
  3. Set in frontend/.env: 
    VITE_ZINIPAY_API_KEY=your_api_key_here
  4. Configure these callback URLs in your ZiniPay merchant dashboard:
    TypeURL
    Redirect (success/fail)https://your-backend.com/payment/callback
    Cancelhttps://your-backend.com/payment/cancel
    Webhook (async)https://your-backend.com/api/payment/webhook
ℹ Webhook security: The webhook endpoint re-verifies every payment directly with the ZiniPay API before updating the booking status. Raw webhook payloads are never trusted.

Mail / Password Reset

Password reset emails require a working SMTP configuration. Set the following in backend/.env:

MAIL_MAILER=smtp
MAIL_HOST=smtp.yourmailprovider.com
MAIL_PORT=587
MAIL_USERNAME=your@email.com
MAIL_PASSWORD=your_smtp_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=noreply@yourdomain.com
MAIL_FROM_NAME="SonyaBus"

You can also update mail settings live from Admin → Integrations → Mail and send a test email to verify the connection.

ℹ Local testing: Set MAIL_MAILER=log to write emails to storage/logs/laravel.log instead of sending them.

Queue Worker & Cron

SMS notifications are dispatched as queued jobs (QUEUE_CONNECTION=database). You need a persistent queue worker process.

Start a worker (basic)

cd backend
php artisan queue:work --tries=3 --sleep=3

Recommended: Supervisor (Linux)

[program:sonyabus-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/sonyabus/backend/artisan queue:work --tries=3 --sleep=3
autostart=true
autorestart=true
numprocs=1
redirect_stderr=true
stdout_logfile=/var/www/sonyabus/backend/storage/logs/worker.log

Laravel Scheduler (optional)

Add this cron entry on the server to run the Laravel scheduler every minute:

* * * * * cd /var/www/sonyabus/backend && php artisan schedule:run >> /dev/null 2>&1

Updating SonyaBus

  1. Back up your database: mysqldump sonyabus > sonyabus_backup.sql
  2. Replace the backend/ and frontend/src/ files with the new version (keep your .env files).
  3. Run composer install --no-dev --optimize-autoloader in backend/.
  4. Run php artisan migrate to apply any new database migrations.
  5. Run php artisan config:clear && php artisan cache:clear && php artisan view:clear.
  6. In frontend/, run npm install && npm run build.
  7. Restart your queue worker: php artisan queue:restart.

Troubleshooting

সাধারণ সমস্যা

SymptomLikely cause & fix
500 Internal Server Error on all pages Storage or cache directory not writable. Run chmod -R 775 storage bootstrap/cache. Also check APP_KEY is set.
Blank white React app VITE_API_BASE_URL is wrong or the backend is unreachable. Open browser DevTools → Network and check the first API call.
CORS errors in browser console Add your frontend domain to config/cors.php → allowed_origins, then run php artisan config:clear.
Payment callback lands on error page Verify APP_URL and APP_FRONTEND_URL in backend/.env match your live domain. Callback URLs in ZiniPay dashboard must also match.
SMS not sending Check queue worker is running (php artisan queue:work). Verify API key and gateway URL in Admin → Integrations → SMS. Use "Send Test SMS" to diagnose.
Password reset email not arriving Check SMTP credentials in .env or Admin → Integrations → Mail. Use "Send Test Email" to verify. Check spam folder.
Admin dashboard shows blank tabs Run php artisan view:clear and hard-refresh the browser (Ctrl+Shift+R).
Seat map shows all seats unavailable Check that the schedule date is today or in the future. Past schedules show all seats as expired.
License wizard: "ENVATO_ITEM_ID is not configured" .env ফাইলে ENVATO_ITEM_ID= এর পরে আপনার CodeCanyon item ID দিন এবং php artisan config:clear চালান।
License wizard: "Invalid or expired personal token" Envato personal token expire হয়ে থাকতে পারে। build.envato.com থেকে নতুন token তৈরি করুন।
License wizard: "purchase code is for a different product" আপনি অন্য কোনো CodeCanyon item-এর purchase code দিচ্ছেন। SonyaBus-এর purchase code ব্যবহার করুন।

cPanel-এ সাধারণ সমস্যা

সমস্যাসমাধান
cPanel-এ site খুললে Object not found বা index দেখায় Subdomain-এর Document Root ভুল সেট আছে। cPanel → Domains → api.yourdomain.com এর Document Root public_html/api/public করুন — public_html/api নয়।
composer: command not found Terminal-এ composer নেই। Local machine-এ composer install --no-dev চালিয়ে vendor/ folder সহ upload করুন। অথবা hosting provider-এর Composer Manager ব্যবহার করুন।
PHP version error: requires PHP 8.2 cPanel → MultiPHP Manager → আপনার domain select করুন → PHP version 8.2 বা higher select করুন।
.env ফাইল দেখা যাচ্ছে না File Manager-এ cPanel File Manager → Settings → "Show Hidden Files (dotfiles)" চেক করুন। .env একটি hidden file।
Database connection error wizard-এ cPanel MySQL-এ database user-কে database-এ assign করতে হয়। cPanel → MySQL Databases → "Add User to Database" → ALL PRIVILEGES দিন। DB_HOST সাধারণত localhost (127.0.0.1 নয়)।
storage/logs write permission error cPanel File Manager → public_html/api/storage → right click → Change Permissions → 755 থেকে 775 করুন। Recursively apply করুন।
React app route refresh করলে 404 হয় public_html/app/.htaccess ফাইল নেই বা ভুল। Installation guide-এর পদক্ষেপ ৮ এর .htaccess content ব্যবহার করুন।
SSL/HTTPS mixed content warning APP_URL এবং APP_FRONTEND_URL উভয়ই https:// দিয়ে শুরু হওয়া উচিত। cPanel → SSL/TLS → Let's Encrypt certificate install করুন।
Cron job কাজ করছে না Terminal-এ which php চালিয়ে সঠিক PHP path বের করুন। Cron command-এ সেই path ব্যবহার করুন, যেমন: /opt/cpanel/ea-php82/root/usr/bin/php

Local (Laragon/XAMPP)-এ সাধারণ সমস্যা

সমস্যাসমাধান
Laragon-এ php artisan serve চালালে port conflict php artisan serve --port=8001 দিয়ে অন্য port ব্যবহার করুন। তারপর frontend .env-এ VITE_API_BASE_URL=http://localhost:8001/api আপডেট করুন।
SQLSTATE: Connection refused error Laragon বা XAMPP-এ MySQL চালু নেই। Laragon → Start All অথবা XAMPP Control Panel → MySQL → Start করুন।
Frontend-এ API call করলে CORS error backend/config/cors.php এ allowed_origins-এ http://localhost:5173 আছে কিনা দেখুন। থাকলে php artisan config:clear চালান।
Windows-এ php artisan key:generate কাজ করছে না .env ফাইল নেই। আগে copy .env.example .env চালান, তারপর php artisan key:generate।
npm install-এ node-gyp error Windows Build Tools install করুন: npm install --global windows-build-tools অথবা Node.js LTS version ব্যবহার করুন (20 LTS recommended)।
Laragon-এ Virtual Host-এ 403 Forbidden Laragon → Menu → Apache → httpd-vhosts.conf edit করুন। Document root backend/public হওয়া নিশ্চিত করুন, backend নয়। Apache restart করুন।
Local-এ License verify হচ্ছে না Internet connection চেক করুন (Envato API call লাগে)। Testing-এর জন্য .env-এ APP_LICENSED=true দিয়ে php artisan migrate manually run করুন।
Queue worker ছাড়া SMS যাচ্ছে না Local-এ আলাদা terminal-এ php artisan queue:work চালান। অথবা testing-এর জন্য .env-এ QUEUE_CONNECTION=sync দিন (synchronous — no worker needed, but blocks the request)।
