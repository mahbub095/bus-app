SonyaBus — Bus Ticket Booking System

Full-stack booking platform · Laravel 12 backend · React 19 customer app · ZiniPay payments · SMS notifications

Introduction

SonyaBus is a complete bus ticket booking system with two separate surfaces:

  • Customer React app — search schedules, choose seats on an interactive seat map, pay online, manage tickets, apply promo codes.
  • Laravel Admin dashboard — manage coaches, routes, schedules, bookings, cancel requests, promotions, users & roles, reports (PDF & Excel), and all gateway settings.

Installation

Step 1 — Upload & extract

Upload the package ZIP to your server and extract it. You should have a backend/ and a frontend/ directory.

Step 2 — Install backend dependencies

cd backend
composer install --no-dev --optimize-autoloader

Step 3 — Configure backend environment

cp .env.example .env
php artisan key:generate

Now edit backend/.env — see the Backend .env section for all required values.

Step 4 — Run migrations & seed demo data

php artisan migrate --seed
⚠ Production note: The seeder creates demo routes, schedules, and three users with password password123. Change all passwords immediately after setup.

Step 5 — Set storage permissions

chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache

Step 6 — Optional: link storage

Run this if the system uses public file uploads (e.g. favicon upload in Site Settings):

php artisan storage:link

Step 7 — Install & build the frontend

cd ../frontend
cp .env.example .env
# Edit frontend/.env — set VITE_API_BASE_URL and VITE_ZINIPAY_API_KEY
npm install
npm run build

The compiled app will be in frontend/dist/. Point your web server document root here for the customer-facing site.

Step 8 — Configure your web server

See the Web Server section for Nginx and Apache examples.

ℹ Vite env files: Variables must be prefixed with VITE_ to be accessible in the browser bundle. After editing .env you must re-run npm run build.

Web Server Configuration

Nginx — recommended setup

Serve the React customer app on the main domain and the Laravel API/admin on a subdomain (or same domain with path-based proxy).

# Customer React app — serves frontend/dist/
server {
    listen 80;
    server_name yourdomain.com;
    root /var/www/sonyabus/frontend/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}

# Laravel backend — serves backend/public/
server {
    listen 80;
    server_name api.yourdomain.com;
    root /var/www/sonyabus/backend/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* { deny all; }
}

Apache — .htaccess (included in backend/public/)

Laravel ships with a public/.htaccess file. Ensure mod_rewrite is enabled and AllowOverride All is set for the document root.

DocumentRoot /var/www/sonyabus/backend/public
<Directory /var/www/sonyabus/backend/public>
    Options -Indexes +FollowSymLinks
    AllowOverride All
    Require all granted
</Directory>

Same-domain deployment (API under /api path)

If you want both on one domain (e.g. yourdomain.com → React, yourdomain.com/api → Laravel), add a proxy location to your Nginx config and set VITE_API_BASE_URL=/api.

location /api/ {
    proxy_pass http://127.0.0.1:8000/api/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

Customer App Overview

The React app is served from frontend/dist/ after building.

  • Search — select origin, destination, date, and optionally coach type (AC / Non-AC).
  • Seat map — interactive seat picker showing available, booked (M/F), and blocked seats. Seats are temporarily held for 2 minutes while the customer completes checkout.
  • Checkout — enter passenger details, apply a promo code, choose payment method, and confirm.
  • Payment — redirects to ZiniPay; on success the booking status is updated to SOLD and an SMS confirmation is sent.
  • My Tickets — authenticated customers can view all their bookings and request cancellations.
  • Offers — displays active promo codes from the admin panel.
  • Maintenance mode — if enabled in Admin → Site Settings, the app shows a maintenance page (site-settings endpoint remains accessible).

ZiniPay Payment Setup

  1. Create a merchant account at zinipay.com and obtain your API key.
  2. Set in backend/.env: 
    ZINIPAY_API_KEY=your_api_key_here
ZINIPAY_BASE_URL=https://api.zinipay.com
  3. Set in frontend/.env: 
    VITE_ZINIPAY_API_KEY=your_api_key_here
  4. Configure these callback URLs in your ZiniPay merchant dashboard:
    TypeURL
    Redirect (success/fail)https://your-backend.com/payment/callback
    Cancelhttps://your-backend.com/payment/cancel
    Webhook (async)https://your-backend.com/api/payment/webhook
ℹ Webhook security: The webhook endpoint re-verifies every payment directly with the ZiniPay API before updating the booking status. Raw webhook payloads are never trusted.

Use these tokens in your SMS message template:

Mail / Password Reset

Password reset emails require a working SMTP configuration. Set the following in backend/.env:

MAIL_MAILER=smtp
MAIL_HOST=smtp.yourmailprovider.com
MAIL_PORT=587
MAIL_USERNAME=your@email.com
MAIL_PASSWORD=your_smtp_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=noreply@yourdomain.com
MAIL_FROM_NAME="SonyaBus"

You can also update mail settings live from Admin → Integrations → Mail and send a test email to verify the connection.

ℹ Local testing: Set MAIL_MAILER=log to write emails to storage/logs/laravel.log instead of sending them.

Queue Worker & Cron

SMS notifications are dispatched as queued jobs (QUEUE_CONNECTION=database). You need a persistent queue worker process.

Start a worker (basic)

cd backend
php artisan queue:work --tries=3 --sleep=3

Recommended: Supervisor (Linux)

[program:sonyabus-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/sonyabus/backend/artisan queue:work --tries=3 --sleep=3
autostart=true
autorestart=true
numprocs=1
redirect_stderr=true
stdout_logfile=/var/www/sonyabus/backend/storage/logs/worker.log

Laravel Scheduler (optional)

Add this cron entry on the server to run the Laravel scheduler every minute:

* * * * * cd /var/www/sonyabus/backend && php artisan schedule:run >> /dev/null 2>&1

Updating SonyaBus

  1. Back up your database: mysqldump sonyabus > sonyabus_backup.sql
  2. Replace the backend/ and frontend/src/ files with the new version (keep your .env files).
  3. Run composer install --no-dev --optimize-autoloader in backend/.
  4. Run php artisan migrate to apply any new database migrations.
  5. Run php artisan config:clear && php artisan cache:clear && php artisan view:clear.
  6. In frontend/, run npm install && npm run build.
  7. Restart your queue worker: php artisan queue:restart.

Troubleshooting

SymptomLikely cause & fix
500 Internal Server Error on all pages Storage or cache directory not writable. Run chmod -R 775 storage bootstrap/cache. Also check APP_KEY is set.
Blank white React app VITE_API_BASE_URL is wrong or the backend is unreachable. Open browser DevTools → Network and check the first API call.
CORS errors in browser console Add your frontend domain to config/cors.php → allowed_origins, then run php artisan config:clear.
Payment callback lands on error page Verify APP_URL and APP_FRONTEND_URL in backend/.env match your live domain. Callback URLs in ZiniPay dashboard must also match.
SMS not sending Check queue worker is running (php artisan queue:work). Verify API key and gateway URL in Admin → Integrations → SMS. Use "Send Test SMS" to diagnose.
Password reset email not arriving Check SMTP credentials in .env or Admin → Integrations → Mail. Use "Send Test Email" to verify. Check spam folder.
Admin dashboard shows blank tabs Run php artisan view:clear and hard-refresh the browser (Ctrl+Shift+R).
Seat map shows all seats unavailable Check that the schedule date is today or in the future. Past schedules show all seats as expired.
