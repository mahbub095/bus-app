Standard Laravel 11 monolith with a single request lifecycle — no external process boundaries between child modules. Cross-child communication is done through direct PHP class instantiation in `app/Services/` (e.g. `BookingService`, `AdminDashboardService`, `SiteSettingsService`, `ZinipayService`) which both the public JSON API (`routes/api.php`) and admin web routes (`routes/web.php`) consume. `bootstrap/app.php` registers middleware (`EnsureUserIsAdmin`, `EnsureLicenseIsActivated`, `CheckMaintenanceMode`, `EnsureUserHasMenuPermission`) that gate every route uniformly, while `database/migrations/` defines the shared schema consumed by all domain children. The installation_flow child bootstraps app state (license, DB, demo seed) before any other child's controllers become reachable, and queued jobs (`Jobs/SendBookingSmsNotification`) plus mail classes provide async side effects across domains.
