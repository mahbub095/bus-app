Two request surfaces share one domain layer: `routes/api.php` serves the customer/admin JSON API (Sanctum bearer tokens) while `routes/web.php` serves the Blade admin dashboard (session auth). Both route sets delegate business logic to `App\Services\*` classes — booking, seat-map, reports, license, SMS, gateway — which operate on shared Eloquent models under `app/Models`. Cross-cutting concerns are centralized in `app/Http/Middleware` (`EnsureUserIsAdmin`, `EnsureLicenseIsActivated`, `CheckMaintenanceMode`, `EnforceAdminSessionTimeout`) and enforced via named middleware groups (`auth:sanctum`, `admin`, `api_admin`, `api_menu:<resource>`). The installation wizard (`InstallController` + `storage/framework/installed` marker) gates all routes until bootstrapped. Admin endpoints mirror Blade controllers 1:1 so the same service layer powers both UIs.
