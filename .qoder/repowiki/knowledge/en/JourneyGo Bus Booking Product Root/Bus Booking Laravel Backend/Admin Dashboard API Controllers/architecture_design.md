Every controller in this scope extends BaseAdminApiController (which itself extends the framework's BaseController) so authentication, pagination, search-term escaping, and the `{data, message}` response shape are uniform across all endpoints. Cross-cutting payload contracts live in the Concerns/FormatsAdminResources trait — each domain controller mixes in only the format* methods it needs (formatStation, formatBus, formatRoute, formatSchedule, formatPromotion, formatUser, parseSeatList), keeping the JSON wire format identical between the per-module REST endpoints and the Blade dashboard's KPI/list responses. Controllers never implement business rules themselves; they call the same App\Services classes used by the Blade routes, which is what keeps the API and web dashboards in sync on data access and validation.
