Three sibling controllers — `BusApiController`, `RouteApiController`, `StationApiController` — all extend `BaseAdminApiController` and use the shared `FormatsAdminResources` concern to normalise Eloquent resources into JSON responses via `formatBus`/`formatRoute`/`formatStation`. Each controller exposes a standard CRUD surface (`index`, `show`, `store`, `update`, `destroy`) with Laravel request validation and pagination through `$this->perPage()` and `$this->itemResponse()`. Query filtering is done with query builder `when(...)` clauses on `search`, type, and foreign-key filters. Business logic that must stay in sync between the Blade form and the API is delegated: route boarding/dropping point lists are validated and duplicate-checked through `App\Services\RouteService`, while bus seat-grid and logo handling live as private helpers (`seatLayoutGrid`, `logoToBase64`). Dependency direction is one-way: controllers depend on Eloquent models (`Bus`, `Route`, `Station`) and, only for routes, on `RouteService`; they never call each other.
