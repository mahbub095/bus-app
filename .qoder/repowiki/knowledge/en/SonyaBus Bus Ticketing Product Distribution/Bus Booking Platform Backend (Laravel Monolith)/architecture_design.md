Single-request Laravel monolith with no external process boundaries between child modules; cross-child communication happens through direct PHP class instantiation in `app/Services/` (e.g. `BookingService`, `AdminDashboardService`, `SiteSettingsService`, `ZinipayService`) consumed by both the public JSON API (`routes/api.php`) and admin web routes (`routes/web.php`). `bootstrap/app.php` registers middleware (`EnsureUserIsAdmin`, `EnsureLicenseIsActivated`, `CheckMaintenanceMode`, `EnsureUserHasMenuPermission`) that gate every route uniformly, while `database/migrations/` defines the shared schema all domain children depend on. The installation_flow child bootstraps app state (license → DB config → demo seed) before other controllers become reachable, and queued jobs (`Jobs/SendBookingSmsNotification`) plus mail classes provide async side effects across domains.
