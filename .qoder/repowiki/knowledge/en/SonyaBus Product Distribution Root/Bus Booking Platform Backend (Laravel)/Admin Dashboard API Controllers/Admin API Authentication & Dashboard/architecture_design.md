Two thin controller classes (`AdminAuthController`, `DashboardApiController`) extend an abstract `BaseAdminApiController` that centralises shared helpers: pagination clamping via `perPage()`, LIKE-term escaping via `likeTerm()`, and response builders `serviceResponse()` / `itemResponse()`. Controllers delegate business logic to dedicated services injected through constructor promotion — `AdminSessionService` (session policy), `AdminDashboardService` / `AdminDashboardAnalyticsService` (dashboard data). Both controllers use the `FormatsAdminResources` trait to serialise Eloquent models into flat arrays. Auth endpoints rely on Laravel Sanctum (`createToken`, `currentAccessToken`) with the `admin` scope and derive token lifetime from the configured idle timeout; dashboard endpoints return paginated payloads shaped by a local `formatPaginator` helper. Dependency direction is one-way: controllers → services → models, with no cross-controller coupling.
