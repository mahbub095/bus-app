The root is a product shell rather than runtime code: it owns the packager (`build-release.ps1`), deployment docs (`CPANEL_DEPLOYMENT_GUIDE.md`, `CODECANYON_RELEASE_GUIDE.md`), and cross-cutting operational guides (security, database/index optimization, SMS gateway) that all child modules reference. The two runtime children — `backend/` (Laravel Sanctum JSON API + Blade admin) and `frontend/` (React/Vite SPA) — communicate over REST using the Sanctum token contract defined in the backend's route files; `load_testing/` exercises those same routes to keep test scenarios aligned with `backend/routes/api.php` and `backend/routes/web.php`. Shared configuration surfaces through `.env.example` files per child, and the Envato license activation flow gates installation across both apps. Release artifacts are produced by stripping vendor/node_modules/.env/cache from the staging build before zipping for CodeCanyon upload.
