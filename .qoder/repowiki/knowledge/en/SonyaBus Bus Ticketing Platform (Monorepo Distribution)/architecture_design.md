The workspace is a product distribution monorepo rather than a single buildable application: `backend/` (Laravel 12 API + Blade admin), `frontend/` (React 19/Vite SPA), and `k6/` (load-test scenarios) are independent deployables communicating over HTTP via Sanctum-authenticated REST endpoints. The root holds shared delivery artifacts — `sonyabus-codecanyon-v1.0.0.zip` plus its unpacked tree are the packaged CodeCanyon release, `build-release.ps1` orchestrates the final zip, `build-frontend.bat` builds the SPA, and `fix-hosts.bat` assists local dev. All cross-cutting operational guidance (security hardening, database/index optimization, SMS gateway setup, cPanel deployment, Envato license activation) lives as top-level Markdown guides so buyers can follow them without touching source code.
