This is a standard Laravel 11 monolith where child modules own their controllers/services/models but share a single request lifecycle — there are no external process boundaries between them. Cross-child communication happens through direct PHP class instantiation in `app/Services/` (e.g. `BookingService`, `AdminDashboardService`, `SiteSettingsService`, `ZinipayService`) which both the public API (`routes/api.php`) and admin web routes (`routes/web.php`) consume. The `bootstrap/app.php` registers middleware (`EnsureUserIsAdmin`, `EnsureLicenseIsActivated`, `CheckMaintenanceMode`, `EnsureUserHasMenuPermission`) that gate every route uniformly, while `database/migrations/` defines the shared schema consumed by all domain children. The installation_flow child bootstraps the app state (license, DB, demo seed) before any other child's controllers become reachable, and queued jobs (`Jobs/SendBookingSmsNotification`) plus mail classes provide async side effects across domains.
