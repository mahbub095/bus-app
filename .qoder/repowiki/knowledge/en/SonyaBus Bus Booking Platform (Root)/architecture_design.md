The workspace is a monorepo-style product distribution rather than a single buildable application: `backend/` (Laravel 12 API + Blade admin), `frontend/` (React 19/Vite SPA), and `k6/` (load-test scenarios) are independent deployables that communicate over HTTP via Sanctum-authenticated REST endpoints. The root holds shared delivery artifacts — `sonyabus-codecanyon-v1.0.0.zip` and `sonyabus-codecanyon-v1.0.0/` are the packaged CodeCanyon release, `build-release.ps1` orchestrates the final zip, `build-frontend.bat` builds the SPA, and `fix-hosts.bat` assists local dev. All cross-cutting operational guidance (security hardening, database/index optimization, SMS gateway setup, cPanel deployment, Envato license activation) lives as markdown guides at this level so buyers can follow them without touching source code.
