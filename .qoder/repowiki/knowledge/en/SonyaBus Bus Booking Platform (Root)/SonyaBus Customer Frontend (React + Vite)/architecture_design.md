Single-page app rooted at `src/main.jsx` → `App.jsx`, which owns all global state (auth token/user, active tab, toast, site settings, API base URL) and renders feature components under `src/components/`. There is no router; navigation is a simple `activeTab` state (`home`, `cancel`, `offers`, `profile`) driving conditional rendering of `BookingPortal`, `MyTickets`, `OffersList`, `UserProfile`. Backend discovery is built into `App.jsx`: on mount it probes `VITE_API_BASE_URL`, then falls back to same-origin `/api`, `localhost:8000/api`, and Laragon-style subdirectory paths, caching the winner in `localStorage` under `sonyabus_api_base`. Auth state lives in `localStorage` keys `sonyabus_auth_token` / `sonyabus_auth_user`; Bearer tokens are attached via an `authHeaders()` helper. The `components/` folder is flat with one component per file (AuthModal, BookingPortal, SeatMap, MyTickets, UserProfile, etc.), each consuming props rather than sharing a context/store. Styling is CSS-only driven by `theme-variables.css` and per-component `.css` files; no UI library is used. Dev proxying is centralized in `vite.config.js`, forwarding `/api`, `/uploads`, and Laragon-specific `/backend/public/*` routes to the configured backend target.
