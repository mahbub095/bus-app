- Report query builders follow a uniform shape: resolve `[start, end]` from `ReportFilterService::resolveDateRange`, eager-load `schedule.bus` and `schedule.route.departureStation|arrivalStation`, apply a status `whereIn`, then delegate shared filters through `applyCommonFilters`.
- Each report type exposes a consistent quartet of methods — a `*Query(Request)` returning an Eloquent Builder, a `format*Row(Model)` producing a keyed array, a `*Headers()` returning column names, and a `*RowToArray(array)` flattening the formatted row into an indexed array for CSV export.
- Date range selection uses a `match`/`switch` over a `period` string key (`today`, `this_month`, `weekly`, `monthly`, `quarterly`, `yearly`, `custom`, etc.) that returns a `[Carbon, Carbon]` tuple, with a default falling back to the current month.
- Mutating operations in `AdminBookingService` return a uniform response envelope `{success: bool, status: int, body: array<string,mixed>}` instead of throwing exceptions or returning raw booleans.
- Optional relationship access uses null-safe chaining (`schedule?->route?->departureStation?->name`) and falls back to sentinel strings like `'N/A'` or empty arrays when relationships are missing.
- Seat counts are derived consistently by splitting the comma-separated `seat_numbers` string via `array_filter(array_map('trim', explode(',', ...)))` before calling `count()`.
