The `backend/` directory is a standard Laravel 11+ application where each child module owns its own `app/Http/Controllers`, `app/Services`, `app/Models`, and Blade views, while cross-cutting wiring lives in three shared locations: `routes/web.php` (admin UI), `routes/api.php` (customer/public API), and `routes/console.php` (Artisan commands from the installation_flow child). Controllers delegate business logic to service classes under `app/Services/` (e.g. `BookingService`, `AdminDashboardService`, `SiteSettingsService`, `ZinipayService`) rather than holding domain logic; Eloquent models under `app/Models/` are the single source of truth for the migration-defined schema in `database/migrations/`. The `bootstrap/app.php` and `config/*.php` files register middleware (`EnsureUserIsAdmin`, `EnsureLicenseIsActivated`, `CheckMaintenanceMode`) and providers that gate both admin and API routes uniformly. Front-end assets (Blade templates under `resources/views/admin`, JS under `resources/js/admin`) are served through the same controllers that render JSON for the public API, making this a monolithic Laravel app with no external process boundary between children — communication happens via direct PHP class instantiation within the request lifecycle.
