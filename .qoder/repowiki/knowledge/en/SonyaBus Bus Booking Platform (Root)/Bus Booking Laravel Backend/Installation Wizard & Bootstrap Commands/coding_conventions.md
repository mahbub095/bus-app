- Long-running installation tasks are delegated from the HTTP controller to a detached child process spawned via `exec('"' . PHP_BINARY . '" "' . base_path('artisan') . '" <command> --token=...')` (with a Windows `start /B` variant), passing a random hex token validated once at the start of the command.
- Background progress is communicated through a JSON status file under `storage/framework/` (one per command) containing `{status, log[, error]}`, written by a private `write`/`flush` helper and polled by the controller's `*Status` endpoints.
- State shared between the web request and the background process is stored in Laravel cache with explicit TTLs (e.g. `now()->addMinutes(10)` for admin credentials, `now()->addMinutes(5)` for the demo-seed token) and cleared after use via `cache()->forget(...)`.
- `.env` mutations go exclusively through `App\Services\EnvFileWriter::set([...])`, which validates key names against `^[A-Z_][A-Z0-9_]*$` and escapes values containing whitespace or braces.
- Commands guard destructive operations with a confirmation prompt unless `--force` is supplied (see `InstallReset`), and wrap multi-step workflows in labeled `$this->task()` blocks that render ✅/❌ per step.
